# Knowledge library

Reusable course material for maintainers. Not learner-facing: a stage's learner-facing
content lives with the stage, under [`modules/`](../modules/).

| Path | Holds |
| --- | --- |
| `retros/` | Findings worth keeping from a run (handover shape, recurring brief problems) |
| `patterns/` | Reusable engineering patterns |
| `rules/` | Project rules distilled from practice |
| `prompts/` | Reusable prompts (e.g. for agents) |
