# Knowledge library

Reusable learning content for this course. Trainer and maintainer material — not trainee-facing.

| Path | Holds | Status |
| --- | --- | --- |
| `proposed/` | Draft lessons, runbooks and exercises curated from engineering work | **Not approved** — awaited review |
| `approved/` | Content that has passed the promotion gate in [`approved/README.md`](approved/README.md) | Approved, verified |
| `retros/` | Findings worth keeping from a run (handover shape, recurring brief problems) | Reference |
| `patterns/` | Reusable engineering patterns | Reference |
| `rules/` | Project rules distilled from practice | Reference |
| `prompts/` | Reusable prompts (e.g. for agents) | Reference |

## Workflow

1. Curate a draft into `proposed/` (see `.opencode/agents/knowledge-curator.md`).
2. Apply the promotion gate in [`approved/README.md`](approved/README.md).
3. Move only content that passes into `approved/`, recording its source stage and the review evidence.

**Nothing may skip `proposed/`.** A file's location is a claim about how much it was checked — `proposed/` means "draft", `approved/` means "verified against real evidence".
